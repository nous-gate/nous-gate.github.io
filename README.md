# نوس · NOUS

موقع شبكة نوس. ثابت بالكامل ويشتغل على GitHub Pages بدون أي سيرفر.

## الصفحات
| الرابط | الصفحة |
|---|---|
| `#home` | الشبكة: البوابة بالنص والفروع تدور حولها |
| `#works` | المعرض + الزبائن والعلامات + آراء الزبائن |
| `#archive` | أرشيف حملة «ما قبل الشكل» (ملف 00 → التريلر) |
| `#order` | ابدأ طلبك: 8 خطوات، والطلب يطلع جاهز لواتساب |
| `#join` | انضم للشبكة (للمصممين) |
| `#about` | عن نوس / AHMED ISMAIL |

## شلون تعدّل المحتوى
كل شي بملف واحد: `assets/js/data.js`

- **رقم الواتساب** → `contact.whatsapp` (مثال `9647701234567`)
- **عمل جديد** → ضيفه بـ `works`، والصورة حطها بـ `assets/works/`
- **مصمم جديد** → `designers`
- **زبون** → `clients` · **رأي زبون حقيقي** → `testimonials`
- **فتح ملف من الحملة** → حط الفيديو بـ `assets/video/` وخلي `released: true`
- **بعد التريلر** → `campaign.revealed: true` يكشف ربط الأقسام بالفروع
- **قبل الإطلاق** → `hideDemo: true` يخفي كل النماذج المؤقتة

## النشر
Settings → Pages → Deploy from branch → `main` / `root`
