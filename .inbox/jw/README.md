# وصولات جوهر

تطبيق موبايل صغير لتسجيل طلبات متجر جوهر وإصدار وصل إلكتروني لكل طلب.

## الرفع على حساب صاحب المتجر (مرة وحدة)
1. سوّي حساب GitHub باسم المتجر، مثلاً `jawhar-store`.
2. سوّي مستودع جديد باسم `jawhar-store.github.io` (اسم الحساب + `.github.io`)، وخليه Public.
3. ارفع ملفات التطبيق للمستودع.
4. بعد دقيقة أو دقيقتين يشتغل على: `https://jawhar-store.github.io`

## التنصيب على موبايل صاحب المتجر
- **آيفون:** افتح الرابط بـ Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد:** افتح الرابط بـ Chrome ← النقاط الثلاث ← «تثبيت التطبيق» أو «إضافة للشاشة الرئيسية».

بعدها يفتح من أيقونة جوهر مثل أي تطبيق، ويشتغل حتى بدون نت.

## أول استخدام
الإعدادات ← رقم المتجر، الإنستغرام، أجور التوصيل، ورقم أول طلب. وبعدها «منتجاتي» للمنتجات اللي تتكرر.

## مهم: البيانات
الطلبات محفوظة على نفس الموبايل وبنفس المتصفح بس:
- كل أسبوع: الإعدادات ← **نسخة احتياطية**، ودزها لنفسك بالواتساب أو احفظها بالدرايف. التطبيق يذكّرك إذا تأخرت.
- إذا تبدّل الموبايل أو انمسح المتصفح: نصّب التطبيق من جديد ← الإعدادات ← **استرجاع نسخة**.
- لا تمسح «بيانات الموقع» أو سجل التصفح الكامل من إعدادات المتصفح.
- **تصدير Excel** يطلّع كل الطلبات بجدول للحسابات.
